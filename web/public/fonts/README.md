# Local font assets

Downloaded 2026-11-20 from the official Google Fonts repository. Files are unmodified.
Original copyright and SIL Open Font License 1.1 notices accompany each family.

| Family | Upstream files | Local notice |
| --- | --- | --- |
| Mukta | https://github.com/google/fonts/tree/main/ofl/mukta — Regular, Medium, SemiBold | Mukta-OFL.txt |
| Hind | https://github.com/google/fonts/tree/main/ofl/hind — Regular | Hind-OFL.txt |
| Noto Serif Devanagari | https://github.com/google/fonts/tree/main/ofl/notoserifdevanagari — NotoSerifDevanagari[wdth,wght].ttf (renamed locally to NotoSerifDevanagari.ttf) | NotoSerifDevanagari-OFL.txt |

The main prototype loads fonts from this directory with no runtime Google Fonts request.
The reading default is Noto Serif Devanagari; Mukta is the interface family. Hind and Mukta
remain reading alternatives in Settings. `../fonts.html` compares identical text at the same size.
Selecting a font does not establish coverage of scripture that has not yet been sourced/reviewed.
